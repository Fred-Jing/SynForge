## 0.1.0 — 2026-10-19

Initial public core extracted from the laboratory workspace.

- Structure-sequence input, synonymous coding search, specialized expression-plasmid design and oligo workbooks.
- Standalone alternating PCA target-layout CLI backed by existing screening/search functions.
- Config-driven Sanger evidence analysis and all-passing-clone exports.
- Whole-plasmid comparison/BAM QC library primitives.
- Explicit-input, layout-specific Azenta workbook adapter.
- Synthetic examples, Chinese/English guidance and automated tests.

The original batch datasets, orders, customer information, supplier workbooks and batch-specific wrappers are not part of this release.
